# Проект: CyberTech 3D — Магазин электроники

## 1. Описание проекта
* **Тема:** Магазин электроники будущего.
* **Название проекта:** CyberTech 3D.
* **Цель страницы:** Продемонстрировать потенциальному покупателю интерактивную 3D-модель флагманского ноутбука с возможностью осмотра со всех сторон.
* **Правило команды:** «Все изменения проверяются другим участником в Pull Request до их объединения с веткой main».

## 2. Состав команды и роли
* **СЕРИКПАЕВА ТУҒАНАЙ  ** — Владелец репозитория, настройка проекта, проведение тестов.
* **СЕРИКПАЕВА ТОЛГАНАЙ ** — Разработка 3D-страницы (запрос к ИИ, интеграция Three.js).
* **КАРИБАЕВА АЙНУР ** — Оформление документации README, проверка Pull Request.

---

## 3. Запрос к ИИ и доработки
* **Использованный промпт:** 
  > «Напиши готовый HTML-код для веб-страницы магазина электроники в одном файле index.html. Используй библиотеку Three.js. На странице должна быть объёмная 3D-модель ноутбука с возможностью поворота мышью или пальцем (OrbitControls). Сделай современный тёмный дизайн и адаптивную верстку.»
* **Что было проверено и исправлено:**
  1. Проверена работа OrbitControls при касании на сенсорных экранах.
  2. Добавлен параметр `touch-action: none;` для предотвращения прокрутки страницы при вращении 3D-объекта на смартфоне.
  3. Проверена адаптивность canvas-контейнера на узких экранах (мобильный вид).

---

## 4. Как мы работали (Ответы на итоговые вопросы)
1. **Где хранились материалы проекта?**
   Все материалы, код и документация хранились в закрытом репозитории GitHub `team-3d-site`.
2. **Кто и какую задачу выполнил?**
   * Участник 1: Подготовка структуры и создание Issues.
   * Участник 2: Генерация и интеграция 3D-страницы index.html через ветку `feature/add-3d-site`.
   * Участник 3: Проверка Pull Request, кросс-устройствный тест и приемка кода.
3. **Как ИИ помог создать 3D-эффект? Что пришлось проверять или исправлять?**
   ИИ сгенерировал базовую сцену Three.js, геометрию объекта и подключил контроллеры вращения. Мы проверили корректность отображения света и настроили реакцию сцены на изменение размеров окна браузера.
4. **Что проверили перед объединением?**
   Соответствие теме, работоспособность 3D-вращения, корректность отображения на смартфонах и отсутствие конфиденциальных данных.
5. **Как команда узнает, кто и когда изменил файл?**
   Через вкладку **Commits** и историю изменений файла в GitHub, где фиксируются автор, время и комментарий к каждому коммиту.
6. **Что вы улучшили бы в следующей версии сайта?**
   Добавили бы загрузку детальной текстуры клавиш, переключатель цветов корпуса ноутбука и анимацию открытия/закрытия крышки.
